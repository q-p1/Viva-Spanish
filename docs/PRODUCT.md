# Product direction

VIVA should feel like a game that teaches Spanish, not an education dashboard wearing game cosmetics.

## Product pillars

1. **Practice until automatic**: recognition is not mastery. Recall speed and repeated production matter.
2. **Help without revealing**: near-miss coaching should explain what kind of error happened without immediately dumping the answer.
3. **Capabilities over XP**: progress means “can order coffee” or “can recover when lost.”
4. **Support fades**: captions and hints disappear phrase-by-phrase when the learner no longer needs them.
5. **Failure becomes curriculum**: repeated personal errors reshape review priority.
6. **Real life wins**: personal phrases and missions make the course reflect the learner's actual life.
7. **Mobile first**: every primary flow must work one-handed on a phone.

## North-star experience

A user starts knowing zero Spanish. Within the first session they confidently say and recall a handful of basics. After repeated sessions, the game quietly reduces translations and pushes those pieces into short real conversations. Story mode arrives only after the user can actually participate.
