# Learning system

## Mastery

Each phrase has a 0–100 mastery score. Correct recall increases mastery with diminishing returns. Fast recall gives a small bonus. Close mistakes cause less loss than large memory gaps.

## Scheduling

Review priority is based on:

- low mastery
- accumulated errors
- how overdue the phrase is

Correct answers push the next review farther into the future. Incorrect answers return quickly.

## Error taxonomy

VIVA currently distinguishes:

- adjacent letter swap
- one missing letter
- one extra letter
- one substituted letter
- word-order error
- accent-only error
- far / memory-gap error

This allows the Coach screen to recommend a practice mode that matches the learner's real weakness.

## Caption Fade

English translation is not globally “on” or “off.” Each phrase earns its way out of captions after its mastery reaches the configured threshold.
