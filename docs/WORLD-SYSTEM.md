# Madrid World System

Madrid World turns mastery into access to places and situations.

## Systems

- 12 city locations
- persistent NPC memory
- relationship state
- dynamic daily events
- local smart NPC responses
- optional remote AI provider
- 12-chapter campaign
- life missions and Passport readiness
- Detective Mode
- Boss Conversations
- No-Caption and Survival tests

NPC memory stores interaction count, remembered facts, relationship score and last reply. Dynamic events are gated by learner readiness so the world does not ask for language the learner has never seen.
